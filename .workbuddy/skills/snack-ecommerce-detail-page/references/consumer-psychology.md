# 消费者心理库 — 零食/儿童零食品类

> 核心原则：不分析产品有什么，而分析消费者为什么买。

## 人群画像

### 典型购买场景
- **购买者**：妈妈（决策+购买者）
- **实际使用者**：孩子
- **影响购买的人**：家庭成员（爸爸、爷爷奶奶）

### 购买原因优先级
1. **孩子喜欢吃** — 第一驱动力
2. **妈妈觉得放心** — 安全感需求
3. **相比普通零食更健康** — 差异化价值

## 消费者核心需求

消费者真正想获得的五样东西：
1. **孩子真实食用场景** — 看到孩子开心的画面
2. **原料展示** — 眼见为实的食材
3. **简单配料** — 看得懂的成分表
4. **产品安全感** — 消除"给孩子吃不健康"的顾虑
5. **妈妈认可感** — "我给孩子选的零食是对的"

## 消费者担心的问题
- **糖** — 怕蛀牙、怕肥胖、怕影响健康
- **添加剂** — 怕香精、色素、防腐剂

## 消费者想看到的信息
- 营养
- 健康
- 天然
- 放心

## 消费者反感的信息
- 过于商业化的吹嘘
- 看不懂的专业术语
- **没有证据的"健康"** — 只喊健康/天然却不给配料表、检测、数据
- **用可爱掩盖信息缺失** — 满屏宝宝萌照，却不告诉你配料表几项、颗粒多大
- **虚假背书** — 伪造检测报告、编造"专家/医生推荐"
- **参数大字报不说人话** — 堆一堆数字，却不翻译成"这对宝宝意味着什么"

## 其他零食子品类消费者画像

### 肉脯类
- **目标消费者**：年轻消费者、学生
- **核心需求**：诱人、高蛋白、原切、优质产地

## 分析框架

面对任何新产品，按以下顺序分析：
1. 谁买单？谁使用？谁影响决策？
2. 购买原因 TOP3 是什么？
3. 消费者真正想获得什么？（不是表面需求，而是深层情感）
4. 他们担心什么？
5. 竞品没有满足什么？
