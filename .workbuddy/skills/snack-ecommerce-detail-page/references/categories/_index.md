## 路由判据（易混淆品类，先判这些）

| 场景 | 判据 | 归属 |
|------|------|------|
| **溶豆 / 米饼 / 磨牙棒 / 宝宝饼干** | 看包装**执行标准号**：标 GB 10769-2025 → 辅食；无辅食国标 → 普通儿童零食 | 有国标 → `infant-food.md`；无 → 零食通用框架 |
| **果泥 / 肉泥** | 标 GB 10770-2025 → 婴幼儿罐装辅助食品；普通果泥 → 零食/饮品 | 有国标 → `infant-food.md`；无 → 零食通用框架 |
| **钙 / 铁 / 锌 / DHA 产品** | 看有无**蓝帽子 + 注册号/备案号** → 保健食品；执行 GB 22570-2014 → 辅食营养补充品；否则为普通食品 | 保健食品 / 普通食品 → `nutrition-supplement.md`；GB 22570 → `infant-food.md` + 叠加 `nutrition-supplement.md` |
| **配方奶粉（婴配粉/儿童奶粉）** | 婴幼儿配方食品 | `dairy.md`（含婴配粉广告法专节） |
| **奶粉 vs 营养品** | 奶粉是"主食/奶"，营养品是"补缺的粒/滴/包" | 分别路由，不混用 |

## 新增品类的标准模板

新建 `references/categories/<品类英文>.md`，至少包含以下章节（参考 `wash-care.md`）：

1. **品类本质** — 和零食 / 其他已建品类的核心区别、购买驱动、说服逻辑；若该品类有强制性国标或特殊法律身份，必须在此写明
2. **消费者画像** — 分购买者/使用者，核心需求、深层需求、最担心、决策关键词（人群多的品类拆 A/B/C 三档）
3. **需求 × 担心 对照表** — 每个需求对应"详情页要回答的问题"
4. **视觉规则** — 配色/摄影/字体/调性/避免方向，每项目附商业理由
5. **竞品常见打法** — 该品类主流玩家的套路 + 我们的差异化机会
6. **FBE 卖点转换示例** — 至少 3 个该品类典型卖点的完整转换（含 ❌废话 vs ✅人话对比）
7. **逐屏策略（弹性框架）** — **禁止写死屏数**；须含：两条硬约束、屏数/文案怎么定的判断逻辑、弹性屏序骨架表（标注必选/建议）、1 个实例
8. **广告法合规专节（必选）** — 该品类的合规红线 + 上线前必查清单；有强制国标/特殊身份的品类须写明标准号与法律身份边界
9. **新增品类后必做的接线清单**（容易漏，逐条打勾）：
   - [ ] `references/categories/_index.md` — 「已建专属画像」加一行 + 触发关键词；若有易混淆品类，补「路由判据」表
   - [ ] `SKILL.md` — description 加该品类触发词；阶段 0 识别示例补一句；「支持的品类」章节加一行
   - [ ] `references/consumer-psychology.md` — 加一行交叉引用（指向新画像）
   - [ ] `README.md` — 顶部品类 badge、当前版本品类表、文件结构树、主要功能品类列举

建好后逐个打勾，避免出现"画像建了但没接线、AI 路由不到"的情形。
