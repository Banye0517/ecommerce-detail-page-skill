# 乳制品品类画像库

> 适用品类：乳制品全类 —— 液态奶（常温奶 / 低温鲜奶 / 儿童奶）、酸奶（低温 / 常温 / 无糖）、奶酪（奶酪棒 / 芝士片 / 马苏里拉）、奶粉（婴幼儿配方粉 / 成人奶粉 / 中老年高钙奶粉）、黄油 / 奶油等。
> 适用平台：淘宝、天猫、京东、拼多多、抖音、孩子王。
> 定位：本文件是该品类的专属画像，AI 接到乳制品类产品时优先加载此文件，再结合通用方法论策划。
> 特别说明：婴幼儿配方奶粉（婴配粉）因广告法极严，策划时除了适用本节通用规则，还须启用「广告法合规·婴配粉专节」，并参考案例 `docs/example-feihe-milk.html`。

## 一、品类本质（和零食 / 洗护 / 日用品 / 小家电的区别）

乳制品是**日常营养刚需 + 部分品类带零食属性**的混合体。它既不像零食纯靠"欲望"，也不像小家电靠"科技参数"，核心信任锚点是**奶源 + 真实营养 + 安全**。

| 维度 | 零食 | 洗护 | 日用品 | 小家电 | 乳制品 |
|------|------|------|--------|--------|--------|
| 购买驱动 | 欲望 | 解决问题 | 解决痛点 | 功能+科技 | 营养刚需 + 口感 + 健康 |
| 决策理性度 | 中低 | 高 | 中高 | 高（参数党） | 中高，家长最较真（给孩子吃） |
| 复购逻辑 | 好吃回购 | 刚需消耗 | 耐用品低复购 | 耐用品极低复购 | **高频消耗，强复购**（家庭常备） |
| 主要担忧 | 糖/添加 | 刺激/无效 | 材质/智商税 | 参数虚标 | 真假奶、糖太多、复原乳、营养宣称虚标、冷链 |
| 情感落点 | 满足 | 安心 | 省心 | 安心/科技感 | 安心（真营养）+ 放心（安全）+ 给孩子最好的 |

**策划要点**：
1. 乳制品是**高频刚需复购品类** → 首屏不必像小家电那样"制造非买不可"，而是"建立奶源信任 + 营养清晰"，让人愿意长期回购。
2. 说服逻辑是"**我先让你相信奶源真 / 营养实，再讲口感 / 便利**"。奶源（黄金奶带、自有牧场、生牛乳）是乳制品专属的信任第一锚点，其他食品品类没有。
3. 信任核心 = **真实奶源 + 配料表透明（生牛乳排第一 / 无复原乳 / 无植脂末）+ 营养数据可查（蛋白 / 钙含量）+ 权威检测 / 认证**。
4. 品类内差异极大：低温鲜奶重"新鲜 + 冷链"，常温奶重"便携 + 保质期"，儿童奶酪棒偏"营养 + 好吃零食感"，婴配粉重"配方科研 + 合规红线"。屏数必须随品类浮动（见第七节）。

## 二、消费者画像

### 画像 A：给孩子买的家长（儿童奶 / 奶酪棒 / 婴配粉 / 学生奶）
- **购买者**：25-40 岁宝妈宝爸，尤其妈妈决策权重高
- **使用者**：0-12 岁儿童
- **核心需求**：真营养、好吸收、口味孩子爱喝、安全无添加
- **深层需求**："给孩子吃的东西不能马虎，要最好的"——负罪感对冲（自己没时间做，靠好产品补）
- **最担心**：糖太多蛀牙、添加剂、植脂末 / 复原乳冒充真奶、营养宣称虚假、孩子不爱喝浪费
- **决策关键词**：生牛乳、高钙、真奶酪、无添加蔗糖、A2、益生菌、配料表干净

### 画像 B：年轻女性自用（低温鲜奶 / 无糖酸奶 / 健身乳清）
- **购买者 = 使用者**：18-35 岁女性，白领 / 健身 / 控糖人群
- **核心需求**：低糖 / 0 蔗糖、高蛋白、口感浓、方便
- **深层需求**："又健康又好吃，不胖"——身材管理 + 自我奖赏
- **最担心**：隐形糖、香精、太稀、智商税（网红噱头）
- **决策关键词**：0 蔗糖、高蛋白、浓稠、生牛乳发酵、无香精

### 画像 C：中老年 / 全家（高钙奶 / 成人奶粉 / 中老年配方）
- **购买者**：40-65 岁，给自己或父母买
- **使用者**：中老年人
- **核心需求**：高钙、易吸收、低乳糖 / 无乳糖、好冲调
- **深层需求**："年纪大了要补钙、要省心"——健康焦虑 + 孝心
- **最担心**：喝了不吸收、乳糖不耐拉肚子、甜腻、假洋牌
- **决策关键词**：高钙、中老年人、无乳糖、骨骼、好吸收

## 四、视觉规则

| 维度 | 方案 | 商业理由 |
|------|------|---------|
| **配色** | 奶白 `#FBF7F0` / 暖米 + 点缀蓝 `#2E86C1`（纯净）或草绿 `#5DAE6E`（天然有机）；儿童线可加活泼黄 / 橙 | 乳制品靠"纯净 + 天然 + 安心"传递信任，奶白底最不踩雷 |
| **摄影** | ① 奶源场景（牧场 / 奶牛 / 挤奶）② 产品特写（挂壁 / 浓稠 / 质地）③ 配料表大字特写（生牛乳第一）④ 营养数据可视化（蛋白 / 钙刻度）⑤ 饮用场景（早餐桌 / 孩子喝 / 健身后） | 乳制品信任 = 奶源 + 配料 + 营养三重证据，画面要逐条可视化 |
| **字体** | 干净圆润无衬线（亲和、食品感），营养数据粗体放大 | 数据一眼可读，圆体降低距离感 |
| **整体调性** | 三个关键词：**纯净、天然、安心** | 和零食"诱人"、小家电"科技"区分 |
| **避免** | 过度炫彩、医疗实验室冷感、虚假"专家推荐"图标、把复原乳拍得像鲜奶 |
| **广告法** | 见下方「广告法合规」专节 |

### 广告法合规（乳制品重点）

**通用乳制品（牛奶 / 酸奶 / 奶酪 / 成人奶粉）**
- **禁止功效宣称**：不使用"增强免疫力""抗癌""降血糖""治疗"等医疗 / 保健功效用语。乳制品是食品，不是药品或保健食品。
- **复原乳必须标示**：若使用复原乳（奶粉冲调），须在包装 / 详情页显著标示"复原乳"，不得冒充鲜奶 / 生牛乳。
- **再制干酪（奶酪棒）新规**：奶酪棒多为"再制干酪"，不得误导消费者为"纯奶酪 / 天然奶酪"；"干酪"含量须如实标注，不得暗示"宝宝的第一口奶酪"等诱导婴幼儿表述。
- **营养声称须达标**："高钙""高蛋白"等声称须符合 GB 28050 营养素参考值要求（如高钙须 ≥ NRV 的 15% / 100g 或 100ml），不能直接写"富含"。
- **"0 蔗糖"≠ 无糖**：0 蔗糖可能含其他糖 / 代糖，不得暗示"无糖无负担""不升糖"，须如实标注总糖。
- **绝对化禁用**：不使用"最 / 第一 / 100% / 唯一真奶源"等绝对化用语。
- **有机 / 牧场认证**：标注"有机"须有有机产品认证，"自有牧场"须可查，不得虚构。

**婴幼儿配方奶粉（婴配粉）专节 —— 极严**
- 禁止明示或暗示**替代母乳**（"贴近母乳""母乳标准""比母乳好"等一律禁用）；不得宣称"母乳化"。
- 禁止**功效绝对化**："益智""聪明""增强抵抗力""提高免疫力""防上火""助睡眠"等均禁用。
- 禁止"最 / 第一 / 100%"等绝对化；"100 种营养"须与真实配料表核对，不得虚标。
- 数据宣称须有实证："吸收率 93%"等须有第三方检测报告，无实证不得直接使用，应改写为"好吸收少负担"等合规表述。
- 禁止医疗专家 / 机构背书暗示疗效；借鉴竞品卖点（如 A2 蛋白、乳铁蛋白、HMO）不得冒用其专利或功效宣称。
- 详见案例 `docs/example-feihe-milk.html` 的"广告法合规"章节。

## 五、竞品常见打法（分析时重点看这些）

1. **奶源故事** — 黄金奶源带（南北纬 40-50°）、自有牧场、进口奶源，用大场景建立信任
2. **配料表透明** — 生牛乳排第一、0 添加、无复原乳，把配料表放大当卖点
3. **营养数据堆** — 蛋白克数、钙含量、益生菌株数，用数据说话
4. **口感种草** — 浓稠挂壁、拉丝、孩子爱喝试饮，用场景建立欲望
5. **细分人群** — 儿童 / 孕妇 / 中老年 / 健身，精准对号入座
6. **低温鲜奶的冷链牌** — 当日 / 72 小时、巴氏杀菌、冷链直达

**差异化机会**：多数只堆"奶源 + 营养"，少有"配料表逐条翻译 + 真实检测 + 口感实证"三位一体。我们的机会是用"奶源可信 + 配料透明 + 营养可查 + 口感场景"组合，让家长 / 自用人群都觉得"这奶真材实料，敢长期回购"。

## 六、FBE 卖点转换示例

### 卖点：儿童奶酪棒（真奶酪 + 高钙 + 0 蔗糖）
- **Feature**：干酪含量 ≥ 51%、添加钙、0 蔗糖、益生元
- **Consumer Truth**：家长怕奶酪棒是糖棍、怕植脂末，又想孩子爱吃补钙
- **Benefit（人话）**：❌ "高钙奶酪棒" ✅ "真奶酪做的，配料表就几样，孩子爱吃还能补点钙"
- **Emotion**：放心、对孩子好、不亏欠
- **Visual**：配料表特写（干酪含量放大）+ 孩子开心吃 + 钙含量刻度 + 0 蔗糖标

### 卖点：低温鲜奶（生牛乳 / 当日 / 高蛋白）
- **Feature**：100% 生牛乳、巴氏杀菌、蛋白质 3.6g/100ml、72h 内
- **Consumer Truth**：想喝真鲜奶，怕复原乳、怕不新鲜
- **Benefit（人话）**：❌ "新鲜好牛奶" ✅ "今天挤今天到，配料表只有生牛乳，蛋白比普通奶高"
- **Emotion**：纯净、新鲜、对自己好
- **Visual**：牧场奶牛 + 挤奶 + 日期标（挤奶日→送达日）+ 配料表只有"生牛乳"大字

### 卖点：无糖酸奶（0 蔗糖 / 生牛乳发酵 / 高蛋白）
- **Feature**：0 蔗糖、生牛乳发酵、蛋白 ≥ 3.2g、无香精
- **Consumer Truth**：想控糖又想好吃，怕网红酸奶隐形糖
- **Benefit（人话）**：❌ "健康酸奶" ✅ "不甜也顺口，浓到挂壁，健身控糖能喝"
- **Emotion**：自律、不胖、满足
- **Visual**：浓稠挂壁特写 + 0 蔗糖标 + 健身后饮用场景 + 蛋白数据

## 七、逐屏策略（乳制品弹性框架，屏数随品类浮动，禁止套固定模板）

乳制品子类差异极大（低温鲜奶可能 6-8 屏，儿童奶酪棒 8-10 屏，婴配粉可达 12 屏），**屏数和文案没有固定值，必须由产品实际情况决定**。两条硬约束：
1. **屏数 = 本品卖点数 + 铺垫屏**（奶源 / 缺口 / 营养 / 配料 / 场景人群 / 规格 / CTA）。每屏只放大 1 个卖点；卖点多的产品自然 10+ 屏。
2. **主文案≤10字、副文案≤12字**（SKILL 铁律，所有屏适用）。

### 屏数 / 文案怎么定（判断逻辑，必须走）
1. **收齐本品输入**：用户上传的**产品名 + 卖点清单**（阶段 0 / 阶段 1）——这是逐屏的"原料"。
2. **搜竞品真实详情页**：网上找 **3-5 家同品类竞品**，打开真实详情页，重点记录：
   - 竞品打了**几屏**、每屏主题、顺序
   - 竞品**文案调性**（奶源故事 / 配料透明 / 营养堆料 / 口感种草）、**视觉风格**
   - 竞品**没讲或讲烂的点**（如只讲奶源没翻配料表、只堆营养没实证）
3. **综合定屏**：`本品卖点数` + `竞品结构参考` + `差异化缺口` → 决定屏数与顺序：
   - 竞品都在讲的点（奶源 / 营养）→ 本品也要有，且用**实证 / 配料表**打得更好
   - 竞品都没讲、本品独有的点 → **单独成屏**，做差异化突破口
4. **文案基于本品**：每屏主 / 副文案从本品卖点提炼，不抄竞品、不套空话（如"新鲜好牛奶"是废话，要写"今天挤今天到，配料只有生牛乳"）。

### 弹性屏序骨架（可增删，非固定）
| 屏序 | 作用 | 是否必选 |
|------|------|---------|
| 首屏 | 产品 + 核心一句话（鲜 / 真 / 营养） | 必选 |
| 奶源屏 | 牧场 / 生牛乳 / 溯源 | 乳制品必选（信任第一锚点） |
| 缺口屏 | 为什么普通奶不行（复原乳 / 糖多） | 建议 |
| 卖点屏 ×N | 每个核心卖点一屏（营养 / 口感 / 0 蔗糖等） | N = 本品卖点数 |
| 配料表屏 | 生牛乳第一 / 配料表与糖含量实拍（勿用"无添加"类用语） | 建议（透明即信任） |
| 场景 + 人群屏 | 早餐 / 孩子 / 健身 / 中老年对号入座 | 必选 |
| 规格 + 认证 | 净含量 / 保质期 / 检测 / 有机认证 | 必选 |
| 行动号召 | 组合装 / 囤货优惠 / CTA | 必选 |

### 无糖酸奶·实例（基于某产品弹性结果，非固定模板）
卖点：0 蔗糖 / 生牛乳发酵 / 高蛋白 / 浓稠挂壁 / 无香精。本例 5 卖点 → 9 屏；**若某鲜奶只有"生牛乳 + 当日达"2 卖点，则为 6-7 屏**，不要硬凑。每屏主文案≤10字、副文案≤12字。

| 屏 | 主文案(≤10) | 副文案(≤12) | 画面 | 设计理由 |
|----|------------|------------|------|---------|
| 1 首屏 | 不甜也好喝 | 生牛乳发酵 | 酸奶杯特写 + 产品 | 痛点开场（控糖又好喝） |
| 2 奶源 | 真生牛乳发酵 | 不是奶粉冲调 | 牧场 + 生牛乳入料 | 乳制品信任第一锚点 |
| 3 糖含量 | 糖只有X克 | 控糖也能喝 | 营养成分表糖含量标注 + 同类对比 | 打消隐形糖焦虑（用数字，不用"不加糖"） |
| 4 高蛋白 | 一杯补点蛋白 | 蛋白看得见 | 蛋白数据刻度 | 强化营养卖点 |
| 5 浓稠 | 浓到能挂壁 | 真材实料 | 挂壁拉丝特写 | 口感实证，建欲望 |
| 6 无香精 | 没有香精味 | 本味才安心 | 配料表干净大字 | 透明即信任 |
| 7 人群 | 谁都适合喝 | 健身早餐控糖 | 多人群拼图 | 对号入座 |
| 8 规格 | 几杯装划算 | 冷链次日达 | 规格 + 配送标 | 消除顾虑 |
| 9 行动 | 现在囤一箱 | 第二件半价 | 组合装 + CTA | 临门一脚 |

### 婴配粉·实例（参考 `docs/example-feihe-milk.html`）
飞鹤案例已按 12 屏弹性框架策划（首屏→痛点→奶源→营养矩阵→吸收→蛋白→IMP→肠道→眼脑→实证→分段→行动），每屏主≤10字/副≤12字，并含婴配粉广告法专节，可直接作为奶粉子类模板复用。

**关键差异**：乳制品是**高频刚需复购**品类，信任靠"奶源 + 配料透明 + 营养可查"三重证据；屏数与文案**不套模板**——以用户上传的产品名 / 卖点为原料，以网上竞品真实详情页为结构参考，动态生成。婴配粉须叠加极严广告法红线。
