# 营养品 / 营养补充剂品类画像库

> 适用品类：以"补缺"为目的的营养补充产品 —— DHA（藻油 / 鱼油）、钙 / 铁 / 锌、维生素 D / AD、益生菌、复合维生素、叶黄素、乳铁蛋白、赖氨酸、胶原 / 铁剂等。
> 适用平台：淘宝、天猫、京东、拼多多、抖音、孩子王、药店。
> 定位：本文件是该品类的专属画像，AI 接到营养品类产品时优先加载此文件，再结合通用方法论策划。
> **本类目最大特点**：产品的**法律身份决定文案边界**——同一个"钙"，做成蓝帽子保健食品和做成凝胶糖果，能写的字完全不同。**策划第一步必须先定身份**（见第一节）。

---

## 一、品类本质（身份先定，再谈策划）

营养品是**目的性极强的"补缺"品类**，说服链为：**缺不缺 → 补不补得上 → 安不安全 → 能不能坚持**。

### 第一步：确认产品身份（三选一，决定合规红线）

| 身份 | 识别方式 | 文案边界 |
|------|---------|---------|
| **A. 保健食品** | 包装有"蓝帽子"保健食品标志 + 保健食品注册号 / 备案号 | 可在**批准的功能范围内**声称，但受《广告法》第十八条严管；广告须显著标明"本品不能代替药品" |
| **B. 普通食品** | 凝胶糖果、固体饮料、饮料、压片糖果等，**无**蓝帽子 | **绝对不得声称任何保健功能 / 功效**，只能依法标注营养成分（GB 28050） |
| **C. 辅食营养补充品** | 执行标准 **GB 22570-2014**（营养包、撒剂、补充片），适用 6-36 月龄 | 属婴幼儿辅助食品，须**同时遵守辅食与营养品两套规则**，另见 `infant-food.md` |

> **最容易翻车的地方**：把 B 当成 A 来写。市面上大量"DHA 软糖""钙固体饮料"是普通食品，文案里一旦出现"增强免疫力""促进吸收""改善睡眠"，即属违法宣称。

### 与零食 / 乳制品 / 辅食的区别

| 维度 | 零食 | 乳制品 | 婴幼儿辅食 | 营养品 |
|------|------|--------|-----------|--------|
| 购买驱动 | 欲望 | 营养刚需 + 口感 | 喂养任务 | **目的性 / 焦虑驱动**（怕缺、怕落后） |
| 决策理性度 | 中低 | 中高 | 极高 | **极高**——看成分、含量、剂型、检测、资质 |
| 复购逻辑 | 好吃回购 | 高频消耗 | 按月龄升级换段 | **长期补充型**，按瓶/月消耗；信任一旦建立换牌意愿极低 |
| 主要担忧 | 糖、添加 | 假奶、虚标 | 过敏、噎呛、月龄 | **含量虚标、吃了没用、不吸收、含糖、重金属、智商税** |
| 情感落点 | 满足、宠爱 | 安心、营养 | 尽责、不焦虑 | **尽责（我做了该做的）+ 对未来的掌控感** |

**策划要点**：
1. 信任核心 = **含量实测（每粒含多少 vs 每日推荐量）+ 剂型与吸收（什么形态好吸收）+ 第三方 / 批次检测 + 资质（蓝帽子 or 备案号 or 生产许可）+ 无多余添加**。
2. **剂型是差异化主战场**：滴剂（控量）、软胶囊、咀嚼片、凝胶糖果、粉剂、撒剂——不同剂型对应不同月龄与接受度，"喂得进去"本身就是卖点。
3. 内容要"**算得出来**"：营养品最有效的说服不是"含量高"，而是"**对照每日推荐量，你每天到底补够没有**"。
4. 严禁焦虑营销：渲染疾病危害、制造健康恐慌本身也违规（见广告法专节第 ④ 条）。
5. 若为 0-6 月龄相关产品，注意**婴儿配方食品不得作含量声称与功能声称**（《食品标识监督管理办法》第三十条，2027-03-16 施行，先按现行法规执行）。

## 二、消费者画像

### 画像 A：0-3 岁宝宝家长（DHA / 维 D / 钙铁锌 / 益生菌）—— 主战场
- **购买者**：妈妈为主（孕期—3 岁），决策权高
- **使用者**：婴幼儿
- **核心需求**：剂量准（滴剂好控量）、原料来源清楚（藻油 vs 鱼油）、无腥味、无添加、能与奶粉 / 辅食同吃
- **深层需求**：**"别人都补，我不补会落后"**——育儿焦虑 + 科学育儿认同
- **最担心**：剂量不好控 / 喂不进去、鱼腥味宝宝拒吃、含糖含香精、重金属污染、宣传夸大不靠谱
- **决策关键词**：藻油 DHA、每日推荐量、无糖无添加、滴管控量、检测报告、适龄

### 画像 B：儿童 / 青少年家长（长高、视力、免疫）
- **购买者**：家长（孩子 6-15 岁）
- **使用者**：孩子
- **核心需求**：好吃愿意吃（咀嚼片 / 软糖）、确有效果感、成分天然
- **深层需求**：**"别输在身高和成绩上"**
- **最担心**：本质只是糖、没效果、孩子吃过量、贵
- **决策关键词**：钙 + 维 D、叶黄素、赖氨酸、无蔗糖、口味好

### 画像 C：年轻女性 / 孕产人群（铁、叶酸、胶原、益生菌）
- **购买者 = 使用者**：18-40 岁，孕产 / 控糖 / 皮肤管理
- **核心需求**：成分明确、剂量足、好吞、不胖、不便秘
- **深层需求**：**"对自己好，也是对宝宝负责"**
- **最担心**：吃了上火 / 便秘、含糖发胖、网红智商税
- **决策关键词**：活性叶酸、铁剂不黑牙不便秘、无糖、独立包装

## 三、核心需求 × 担心 对照表

| 需求 | 对应担心 | 详情页要回答的问题 |
|------|---------|-------------------|
| 补得准 | 剂量虚标、吃不够 | "每粒 / 每滴含多少？对照每日推荐量是多少？" |
| 吸收好 | 吃了没效果 | "什么剂型？有没有可引用的吸收相关依据？" |
| 够安全 | 重金属 / 污染物 | "有第三方检测报告吗？原料哪来的？" |
| 孩子肯吃 | 腥味 / 难吞 / 拒绝 | "什么口味？什么剂型？能混在奶里吗？" |
| 配料干净 | 含糖 / 香精 / 添加剂 | "配料表有糖吗？无糖是怎么做到的？" |
| 值不值 | 智商税 | "和同类比含量与单价怎么算？资质是什么？" |

## 四、视觉规则

| 维度 | 方案 | 商业理由 |
|------|------|---------|
| **配色** | 按人群分线：婴童线柔蓝 `#A8CADF` / 柔黄 `#F2D98D` + 白底；儿童线活力橙绿；女性线低饱和裸粉 `#E8D5D0` / 高级灰。统一规则：**白底 + 一个主色** | 白底传递"科学、可核查"；刻意避开保健品传统的金色 / 大红药品感 |
| **摄影** | ① 剂型特写（滴管取量、胶囊通透感、软糖质感）② **剂量可视化**（一粒 = 多少含量，用刻度 / 对比呈现）③ 原料来源（藻油、乳矿物盐、菌株）④ 检测报告与资质（蓝帽子标志、备案号）⑤ 使用场景（滴进奶里、早餐桌、随身携带） | 营养品的信任来自"可核查"，每一张图都应是证据，而非氛围 |
| **字体** | 无衬线，**含量数字粗体最大化**（"每粒 100mg"必须是视觉主体） | 含量是本类目第一卖点，数字要让家长一眼看清 |
| **整体调性** | 三个关键词：**科学、克制、可核查** | 与零食"诱人"、辅食"安全可信"、乳制品"纯净"区分 |
| **避免** | 药品感（像药 → 家长不敢长期给孩子吃）、金色奢华感（像中老年保健品）、夸大特效大字报、焦虑渲染（病态图片 / 吓人对比图） | 药品感吓跑长期用户，焦虑渲染本身违规 |
| **广告法** | 见下方「广告法合规」专节——**营养品是全品类里合规风险最高的类目** | |

### 广告法合规（营养品重点 —— 本类目最高风险区）

> **重要时效提示**：《食品标识监督管理办法》（市场监管总局令第 100 号）**已公布，2027-03-16 施行**；在此之前仍须同时遵守现行《食品安全法》《广告法》等。**上线前必须复核。**

**① 保健食品广告"六不得"（《广告法》第十八条）**
保健食品广告不得含有下列内容：
1. **表示功效、安全性的断言或者保证**（"效果显著""绝对安全""无任何副作用"）
2. **涉及疾病预防、治疗功能**（"改善便秘""预防贫血""助眠""抗过敏"）
3. **声称或者暗示为保障健康所必需**
4. **与药品、其他保健食品进行比较**
5. **利用广告代言人作推荐、证明**（含以专家、医务人员、消费者名义或形象作功效证明）
6. 法律、行政法规规定禁止的其他内容

> 保健食品广告**应当显著标明"本品不能代替药品"**。此外，网络销售保健食品的**主页面显著位置**须标注"保健食品不是药物，不能代替药物治疗疾病"等消费提示（《食品标识监督管理办法》第三十六条）。

**② 其他高频违规点（《保健食品广告审查暂行规定》第八条）**
- 不得含有"**安全**""**无毒副作用**""**无依赖**"等承诺性表述
- 不得含"**最新技术**""**最高科学**""**最先进制法**"等绝对化用语
- 不得含**无法证实**的"科学或研究发现""实验或数据证明"
- 不得**渲染、夸大健康状况或疾病危害**制造恐慌（暗示不买会得病同样违规）
- 不得含有效率、治愈率、评比、获奖等综合评价内容
- 不得宣称祖传秘方、无效退款、保险公司保险

**③ 普通食品形态营养品的红线（最易踩）**
- **不得声称保健功能 / 功效**："保健食品之外的其他食品不得在食品标识中声称具有保健功能（功效）"（《食品标识监督管理办法》第七条第二款）
- **不得涉及疾病预防、治疗功能**（同办法第七条第一款）
- **不得无依据标称"适合未成年人食用"**（同办法第八条）→ 儿童营养品须有法规 / 标准依据
- 营养声称（"高钙""高蛋白""富含"）须符合 **GB 28050** 条件，不能凭感觉写

**④ 通用红线**
- 禁用绝对化用语：最、第一、100%、唯一、顶级
- 不得冒用他人专利、不得虚构专利或认证
- 对比竞品不得指名贬低
- 婴幼儿相关须标注适宜 / 不适宜人群与食用量

**⑤ 处罚量级（写文案前先知道代价）**
《广告法》第五十八条：违反第十八条发布保健食品广告的，责令停止发布、消除影响，处广告费用 **1-3 倍**罚款；广告费用无法计算或明显偏低的，处 **10-20 万元**；情节严重的处 **3-5 倍**或 **20-100 万元**，**可以吊销营业执照**，并由广告审查机关撤销广告审查批准文件、一年内不受理其广告审查申请。

**⑥ 上线前必查清单**
1. 产品身份是保健食品（蓝帽子）还是普通食品？（决定全部文案边界）
2. 若为保健食品：宣称是否在**批准的功能范围**内？是否标了"本品不能代替药品"？
3. 是否有任何疾病预防 / 治疗表述？是否渲染了健康危害制造恐慌？
4. 是否出现功效断言、安全性保证、"安全 / 无副作用 / 无依赖"？
5. 是否有专家 / 医生 / 消费者证言式背书？
6. 含量数据是否有检测依据？"每日推荐量"引用来源是否可靠？
7. 是否出现绝对化用语、"最新技术 / 最高科学"？
8. 若为儿童产品：标称"适合未成年人食用"是否有标准依据？

## 五、竞品常见打法（分析时重点看这些）

1. **原料来源故事** — 藻油 vs 鱼油、乳矿物盐、专利菌株、活性叶酸，用来源建立品质区分
2. **含量堆料对比表** — 每粒含量 vs 竞品 vs 每日推荐量
3. **剂型创新** — 滴剂控量、软糖好吃、撒剂可混食，解决"喂不进去"
4. **检测与资质前置** — 蓝帽子、备案号、第三方检测、批次报告
5. **育儿知识科普引流** — "宝宝 6 个月后为什么容易缺铁"，用知识建立专业感
6. **专家科普内容** — ⚠️ 注意：科普身份可用，但**不得以专家 / 医务人员名义为功效作证明**

**差异化机会**：绝大多数竞品只会堆"含量高 + 成分好"，**很少把"每日推荐量对照 + 剂量可视化 + 批次检测 + 剂型适配月龄"讲成一个可核查的系统**。我们的机会：把"感觉有用"升级为"**算得出来有用**"——让家长打开详情页就能算清"我家宝宝每天到底补够没有"。这既是最强的转化逻辑，也天然规避违规（讲数据和依据，不讲功效）。

## 六、FBE 卖点转换示例

### 卖点：婴幼儿藻油 DHA 滴剂
- **Feature**：藻油 DHA，每滴固定含量，滴管控量，无糖无腥味
- **Consumer Truth**：家长知道要补 DHA，但不知道补多少、怕鱼腥味、怕胶囊吞不下
- **Benefit（人话）**：❌ "高含量 DHA" ✅ "一滴就是一天的量，滴进奶里没腥味，不用掰胶囊"
- **Emotion**：省心、精确、我补对了
- **Visual**：滴管取量特写（一滴）→ 滴入奶瓶场景 → 每滴含量 vs 每日推荐量刻度 → 藻油原料来源图（规避"深海污染"顾虑）

### 卖点：儿童钙 + 维 D 咀嚼片
- **Feature**：钙 + 维 D 复合配方，无蔗糖，奶味
- **Consumer Truth**：孩子不肯吃钙片；家长听说"单补钙不吸收"；又怕太甜蛀牙
- **Benefit（人话）**：❌ "高钙咀嚼片" ✅ "加了维 D 一起补，无蔗糖不蛀牙，奶味孩子自己嚼"
- **Emotion**：放心、孩子愿意吃
- **Visual**：钙 + 维 D 协同的简化图解 → 无蔗糖配料表 → 孩子自己嚼着吃的场景 → "每天 1 片"剂量刻度

### 卖点：孕产 / 女性益生菌（若为保健食品身份）
- **Feature**：特定菌株，独立铝箔袋，常温保存
- **Consumer Truth**：孕期排便不顺，怕吃通便产品影响宝宝，怕常温存活率低
- **Benefit（人话）**：⚠️ **此处必须按身份改写**——
  - 若为保健食品：只能写"每日补充 X 亿活菌，独立包装常温带着走"，**不得写"改善便秘 / 解决孕期排便问题"**（涉疾病治疗）
  - 若为普通食品：**不得声称任何保健功能**，只能讲菌株名、活菌数、配料表
- **Emotion**：安心、不焦虑
- **Visual**：菌株名称 + 活菌数 → 独立袋便携场景 → 常温保存依据说明（须有依据）→ 孕期日常场景
- **设计理由备注**：本示例刻意保留"⚠️ 身份改写"说明，因为**营养品的卖点转换必须在合规框架内完成**，FBE 输出里出现违规文案等于把风险交给客户。

## 七、逐屏策略（营养品弹性框架，屏数随产品浮动，禁止套固定模板）

营养品的必选屏与所有其他品类都不同：**资质屏、含量对照屏、剂型屏是营养品独有的三块**，缺了就无法建立"可核查"的信任。

两条硬约束（沿用 SKILL 铁律）：
1. **屏数 = 本品卖点数 + 铺垫屏**（缺口 / 资质 / 含量 / 剂型 / 检测 / 人群 / 规格 / CTA）。每屏只放大 1 件事。
2. **主文案 ≤ 10 字、副文案 ≤ 12 字**。

### 屏数 / 文案怎么定（判断逻辑，必须走）
1. **先定身份**：保健食品 / 普通食品 / 辅食营养补充品（GB 22570）——这一步没做完，禁止开始写文案。
2. **收齐本品输入**：产品名 + 卖点清单 + 含量数据 + 资质信息 + 适宜人群。
3. **搜竞品真实详情页**：找 3-5 家同成分竞品（DHA 对 DHA、钙对钙），记录：几屏、有没有含量对照、有没有亮资质、竞品在回避什么（很多竞品不敢亮资质）。
4. **综合定屏**：竞品都讲的（成分来源、含量）→ 用**对照每日推荐量**打得更实；本品独有的（剂型、检测、资质）→ 单独成屏。
5. **文案基于本品**：不抄竞品、不套空话。"高含量 DHA"是废话，要写"一滴就是一天的量"。

### 弹性屏序骨架（可增删，非固定）
| 屏序 | 作用 | 是否必选 |
|------|------|---------|
| 首屏 | 产品 + 人群 + 补什么（"给 6 个月后的宝宝补 DHA"） | 必选 |
| 缺口屏 | 为什么这个人群容易缺（**科普语气，禁渲染疾病危害**） | 建议 |
| 资质屏 | 蓝帽子 / 备案号 / 执行标准 / 生产许可 | **营养品必选（独有）** |
| 含量屏 | 每粒 / 每滴含多少 vs 每日推荐量 | **必选（核心屏）** |
| 剂型屏 | 滴剂 / 咀嚼片 / 软糖 / 粉剂 / 撒剂 → 适配月龄与接受度 | **必选（独有）** |
| 原料屏 | 藻油 / 乳矿物盐 / 菌株 / 活性叶酸等来源 | 卖点屏 ×N |
| 安全屏 | 第三方检测 / 重金属 / 无糖无添加 / 不适宜人群 | 必选 |
| 场景 + 人群屏 | 早餐 / 睡前 / 混奶 / 外出携带 | 必选 |
| 规格 + 坚持屏 | 一瓶能吃多久 / 装量 / 囤货 | 必选 |
| 行动屏 | 组合装 / 周期装 / CTA | 必选 |

### 婴幼儿藻油 DHA 滴剂 · 实例（8 屏，非固定模板）
卖点：藻油来源、每滴固定含量、滴管控量、无糖无腥味。本例 4 卖点 → 8 屏；**若某维生素软糖只有"无蔗糖 + 口味好"2 卖点，则为 5-6 屏**，不要硬凑。

| 屏 | 主文案(≤10) | 副文案(≤12) | 画面 | 设计理由 |
|----|------------|------------|------|---------|
| 1 首屏 | 六个月后补 DHA | 一滴就够一天 | 滴管 + 一滴特写 | 锁定人群与剂量，第一眼给"好操作" |
| 2 缺口 | 母乳之外要吃 | 6 月后开始 | 月龄时间轴（不渲染疾病） | 用科普讲"为什么现在开始"，不制造恐慌 |
| 3 资质 | 资质都在这 | 备案号可查 | 蓝帽子 / 备案号特写 | 营养品信任第一锚点，很多竞品不敢亮 |
| 4 含量 | 一滴含多少 | 对照推荐量 | 含量刻度 vs 每日推荐量 | 核心屏：把"感觉有用"变成"算得出来" |
| 5 剂型 | 滴管好控量 | 不用掰胶囊 | 滴管取量演示 | 解决"喂不进去、量不准"这一最大摩擦 |
| 6 原料 | 藻油更干净 | 不是鱼油 | 藻油来源图 | 回应腥味与污染顾虑（讲来源，不讲功效） |
| 7 安全 | 无糖无添加 | 检测报告在这 | 配料表 + 检测页 | 家长长期吃的前提是"干净" |
| 8 行动 | 一瓶吃一个月 | 两瓶更划算 | 规格 + CTA | 长期补充型品类，按周期装提升复购 |

**关键差异**：营养品的信任双锚点是**资质 + 含量**（区别于辅食的"国标"锚点、乳制品的"奶源"锚点）；且**文案边界完全由法律身份决定**——同样的产品成分，蓝帽子和凝胶糖果能写的字完全不同。策划时必须先定身份，再动笔。
