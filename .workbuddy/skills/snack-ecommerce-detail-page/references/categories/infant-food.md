# 婴幼儿辅食（婴童食品）品类画像库

> 适用品类：供给 **6-36 月龄**较大婴儿和幼儿食用的婴幼儿辅助食品，共三类——
> ① 婴幼儿谷类辅助食品（米粉、高蛋白米粉、婴幼儿面条、颗粒面、米饼、磨牙棒、谷物脆）
> ② 婴幼儿罐装辅助食品（果蔬泥、肉泥、鱼泥、颗粒果蔬/肉泥、婴幼儿果蔬汁）
> ③ 辅食营养补充品（辅食营养包、辅食营养素补充片、钙/铁/锌撒剂）
> 适用平台：淘宝、天猫、京东、拼多多、抖音、孩子王、线下母婴店。
> 定位：本文件是该品类的专属画像，AI 接到辅食类产品时优先加载此文件，再结合通用方法论策划。
> **注意**：普通儿童零食（3 岁以上、无辅食国标）不属于本画像，走零食通用框架；乳制品（配方奶粉）走 `dairy.md`。

## 一、品类本质（和零食 / 乳制品的区别）

婴幼儿辅食是**受强制性国标约束的"特殊膳食用食品"**，不是普通食品，更不是零食。消费者买的不是"好吃"，而是**"我喂得对"**。

现行执行标准（上线前须核对最新版本与实施日期）：

| 类别 | 执行标准 | 适用月龄 | 典型产品 |
|------|---------|---------|---------|
| 婴幼儿谷类辅助食品 | GB 10769-2025（2026-03-16 实施） | 6-36 月龄 | 米粉、面条、饼干、磨牙棒 |
| 婴幼儿罐装辅助食品 | GB 10770-2025（2026-03-16 实施） | 6-36 月龄 | 果泥、肉泥、果蔬汁 |
| 辅食营养补充品 | GB 22570-2014 | 6-36 月龄 | 营养包、撒剂、补充片 |

> **2025 版新国标的三个升级点，正好是最好的传播素材**：① 原料禁用扩至**蜂蜜、氢化油脂、经辐照处理的原料**；② 添加糖总量压到 **≤0.6g/100kJ**；③ 谷类辅食要求**谷物干物质占比 ≥50%**，且必须标注完整类别名称（如"婴幼儿高蛋白谷物辅助食品"），不得简化模糊。

| 维度 | 零食 | 乳制品 | 婴幼儿辅食 |
|------|------|--------|-----------|
| 购买驱动 | 欲望（想吃） | 营养刚需 + 口感 | **喂养任务 / 发育刚需**（不吃不行） |
| 决策理性度 | 中低，易被画面打动 | 中高，家长较真 | **极高**——家长会看配料表、执行标准号、过敏原、颗粒尺寸 |
| 产品身份 | 普通食品 | 普通食品 / 特殊膳食 | **特殊膳食用食品（有强制性国标）** |
| 复购逻辑 | 好吃就回购 | 高频消耗 | **按月龄阶段消耗，会随月龄升级换段**（强复购 + 客单爬坡） |
| 主要担忧 | 糖、添加剂 | 假奶、营养虚标 | **过敏、噎呛、不符合月龄、配料不干净、营养只是填充淀粉** |
| 情感落点 | 满足、宠爱 | 安心、营养 | **尽责（我喂得对）+ 不焦虑** |

**策划要点**：
1. 说服逻辑是"**先拿资格，再讲内容**"——先用执行标准号 + 月龄适配证明"我有资格给这个月龄的宝宝吃"，再讲营养、适口性、便利。顺序和零食完全相反。
2. 信任核心 = **执行标准号（GB 10769-2025 等）+ 配料表干净（无蜂蜜/无氢化油脂/无添加糖/无香精色素防腐剂）+ 月龄分阶 + 冲调与进食实证**四件套。
3. **分阶是辅食独有的卖点结构**：6M+ / 8M+ / 12M+ / 18M+ 的质地、颗粒大小、用量都不同。详情页**必须有分阶对照**，否则妈妈不知道自己该买哪款。
4. 辅食的消费者是**"学习型家长"**——新手妈妈不懂怎么喂。谁把"几月吃、吃多少、怎么冲、什么质地"讲清楚，谁赢。信息密度 > 画面美感。
5. 营养补充品（GB 22570）在合规上**同时受辅食国标与营养品规则约束**，若产品是营养包/撒剂，须叠加阅读 `nutrition-supplement.md`。

## 二、消费者画像

### 画像 A：新手妈妈（6-12 月龄，辅食添加初期）—— 主战场
- **购买者**：妈妈，25-35 岁，多为第一次当妈，决策权接近 100%
- **使用者**：6-12 月龄婴儿
- **核心需求**：绝对安全合规、单一成分好排敏、冲调顺滑不结块、宝宝肯吃
- **深层需求**：**"我不能搞砸宝宝的第一次辅食"**——焦虑型尽责，怕过敏、怕噎到、怕营养跟不上
- **最担心**：过敏（牛奶蛋白 / 麸质）、配料里有糖盐蜂蜜香精、冲不开结块、宝宝不吃浪费、买错月龄
- **决策关键词**：6M+、无添加、单一谷物、有机、过敏原提示、冲调比例、执行标准号

### 画像 B：进阶期家长 / 带娃长辈（12-36 月龄）
- **购买者**：妈妈 + 祖辈（白天带娃的人）
- **使用者**：12-36 月龄幼儿
- **核心需求**：营养密度（高蛋白 / 高铁 / 高钙）、口感有趣（磨牙棒、饼干）、便携（外出携带）、能自己抓着吃
- **深层需求**：**"宝宝吃得开心又长得好"**——从焦虑期转向效率期
- **最担心**：硬度过高噎呛、太甜上瘾、只是零食没营养
- **决策关键词**：12M+、高蛋白、磨牙棒、独立小包、不加糖

### 画像 C：送礼 / 囤货型（旁支）
- **购买者**：亲戚、同事、朋友（满月礼 / 周岁礼）；或家长大促囤货
- **决策特征**：决策粗——认品牌、认进口、认国标、看礼盒体面
- **详情页要照顾**：礼盒组合、大包装性价比、"一份够吃多久"

## 四、视觉规则

| 维度 | 方案 | 商业理由 |
|------|------|---------|
| **配色** | 暖米白 `#FBF8F2` 打底 + 分阶用色系统：6M+ 柔蓝 `#A8CADF`、8M+ 浅黄 `#F2D98D`、12M+ 草绿 `#9CC49B`、18M+ 暖橙 `#EBAF7C` | 白底建立"干净、医用级可信"；**分阶用色让妈妈一眼找到自己宝宝的段位**，这是辅食独有的信息设计手段 |
| **摄影** | ① 冲调过程实拍（粉 → 糊的状态变化）② 质地特写（顺滑挂壁 / 颗粒尺寸对比米粒硬币）③ 宝宝真实进食反应（张嘴吃，而非摆拍大笑）④ 月龄分阶对照图（质地 / 颗粒 / 用量）⑤ 执行标准号与配料表特写 | 辅食信任靠"证据"不靠"氛围"：冲调演示证明好用、颗粒对比证明确实防噎、配料表特写证明干净 |
| **字体** | 圆润无衬线，**月龄、含量、颗粒 mm 数用粗体放大** | 参数即卖点，家长要的是可核查的数字 |
| **整体调性** | 三个关键词：**安全、可信、有耐心** | 区别于零食的"诱人"、洗护的"专业"、乳制品的"纯净" |
| **避免** | 过度卡通幼稚化（显不专业）、把辅食拍成大人甜品、"专家 / 医生推荐"式虚假背书、用宝宝超萌表情替代实质信息 | 家长要的是信息，不是萌；炫萌会稀释"专业可信"这个核心资产 |
| **广告法** | 见下方「广告法合规」专节——辅食是**有强制性国标的特殊膳食食品**，宣称边界比零食更窄 | |

### 广告法合规（婴幼儿辅食重点）

> **重要时效提示**：以下依据中，《食品标识监督管理办法》（市场监管总局令第 100 号）**已公布但 2027-03-16 才施行**；在此之前仍须同时遵守现行《食品安全法》《广告法》与 GB 7718 等标签标准。**上线前必须复核最新版本与生效状态**。

**① 资格红线（辅食专属）**
- **不得无依据标称"适合未成年人食用"**：《食品标识监督管理办法》第八条明确"没有法律、法规、规章、食品安全国家标准或者行业标准依据的，食品标识不得标称适合未成年人食用"。→ 普通儿童零食**不可伪装成辅食**；真正辅食**必须标注执行标准号**（GB 10769-2025 / GB 10770-2025 / GB 22570-2014），这是辅食的"安全身份证"。
- **名称必须完整规范**：须标注完整类别全称（如"婴幼儿高蛋白谷物辅助食品""婴幼儿生制类谷物辅助食品"），不得简化模糊或自行造词。

**② 配料禁用与限量（GB 10769/10770-2025）**
- **不应使用**：蜂蜜、氢化油脂、经辐照处理的原料。
- **添加糖限量**：谷类辅食中添加蔗糖 / 果糖 / 葡萄糖 / 葡萄糖浆一种或多种，总量 **≤0.6g/100kJ**。→ 文案可讲"不加白砂糖"，但**不可笼统写"无糖"**（可能含其他糖类）。
- **不得添加香精、色素、防腐剂**：1 岁以内不需要额外调味，可作为卖点讲"配料表干净"。

**③ 禁止保健功能与疾病宣称**
- **非保健食品不得声称保健功能**："保健食品之外的其他食品不得在食品标识中声称具有保健功能（功效）"（《食品标识监督管理办法》第七条第二款）。→ **禁止**"增强免疫力""促进大脑发育""提高抵抗力"。
- **禁止涉及疾病预防、治疗功能**（同办法第七条第一款）。→ **禁止**"预防贫血""改善便秘""缓解湿疹""助消化"。
- **不得暗示替代母乳或配方奶**：辅食是"补充"，不能写"可以代替奶粉 / 母乳"。

**④ 数据与背书**
- "高铁""高钙""高蛋白"等营养声称须符合 GB 28050 / GB 13432（预包装特殊膳食用食品标签）的声称条件，**不能凭感觉写"富含"**。
- "有机"须有有效有机产品认证；"进口奶源 / 有机原料"须可溯源。
- **禁用绝对化用语**：最、第一、100%、唯一、冠军等。
- 不得以医疗机构、专家、医生名义或形象为功效作证明。

**⑤ 标签强制提示**
- 颗粒 / 片（块）状罐装辅助食品**须标注**"本产品含颗粒、片（块）状物，食用时请注意吞咽安全"（GB 10770-2025）。→ 详情页应复现该提示，反而强化"我们连吞咽安全都管"的专业感。

**⑥ 上线前必查清单**
1. 执行标准号是否与实物一致、是否为现行版本？
2. 配料表是否出现蜂蜜 / 氢化油脂 / 香精 / 色素 / 防腐剂？
3. 添加糖是否在限量内？文案是否误写"无糖"？
4. 有无任何保健功能或疾病防治表述？
5. 营养声称是否有 GB 28050 / GB 13432 依据？
6. 月龄标注是否有标准依据？颗粒尺寸是否如实标注？
7. 是否出现绝对化用语、专家/医生背书、竞品贬低？

## 五、竞品常见打法（分析时重点看这些）

1. **国标符合性前置** — 直接亮执行标准号，把 2025 版新国标的"禁蜂蜜 / 禁氢化油脂 / 限糖"当成抢先打的信任状
2. **月龄分阶体系** — 6M+ / 8M+ / 12M+ 产品矩阵，做"选段导航"，降低妈妈的选择成本
3. **单一成分 / 低敏** — 单一谷物、无麸质、过敏原明示
4. **有机认证** — 有机米粉 / 有机果泥，认证证书放大展示
5. **冲调演示** — 水温水量、不结块对比、稀稠度分阶
6. **独立小包** — 一次一包、便携防潮、按次控量

**差异化机会**：多数辅食详情页只堆"有机 / 无添加"这类形容词，**很少把国标要求逐条对应成"妈妈能查的表"**。我们的机会是**质检式透明**——把国标条文翻译成三问："有蜂蜜吗？有添加糖吗？颗粒多大？"，用"可核查"建立专业信任，这是拉不开就没人能抄的壁垒（因为要真合规才敢这么写）。

## 六、FBE 卖点转换示例

### 卖点：婴幼儿高铁米粉（6M+，单一谷物）
- **Feature**：执行 GB 10769-2025，铁强化，单一谷物，独立小包
- **Consumer Truth**：新手妈妈知道"6 个月后母传铁耗尽"，但不知道自己补没补够，更怕米粉里加糖加香精
- **Benefit（人话）**：❌ "宝宝第一口辅食" ✅ "6 个月后铁得靠吃，一次一包按比例冲，配料表就五样"
- **Emotion**：我喂得对、不焦虑
- **Visual**：月龄 → 铁需求简单刻度图 + 冲调不结块演示 + 配料表 5 项大字 + 独立小包"一次一包"

### 卖点：婴幼儿果泥 / 肉泥（罐装辅食）
- **Feature**：执行 GB 10770-2025，不加糖，商业无菌常温保存，6-12 月龄颗粒 <5mm
- **Consumer Truth**：怕市售果泥加糖、怕开封存不住、怕颗粒大噎到
- **Benefit（人话）**：❌ "营养果泥" ✅ "就是水果打成泥，配料表就两样，颗粒比米粒小，常温能放"
- **Emotion**：放心、省事
- **Visual**：单一水果原料图 → 泥状质地特写 → 颗粒尺寸与米粒 / 硬币对比 → 常温保存说明

### 卖点：磨牙棒 / 米饼（12M+ 自主进食）
- **Feature**：执行 GB 10769-2025（其他婴幼儿谷物辅助食品），不加糖不加盐，易化不噎
- **Consumer Truth**：想让宝宝自己抓着吃，但怕太硬崩牙、怕噎、怕太甜上瘾蛀牙
- **Benefit（人话）**：❌ "磨牙饼干" ✅ "口水一泡就化，不加糖不上瘾，12 个月自己抓着啃"
- **Emotion**：安心、看着宝宝自己长大
- **Visual**：硬度 / 易化演示（掰断、泡水软化）+ 宝宝手抓特写 + 不加糖配料表 + 分阶月龄标注

## 七、逐屏策略（辅食弹性框架，屏数随产品浮动，禁止套固定模板）

辅食的必选屏与零食差别很大：**分阶屏、国标屏、冲调/食用演示屏是辅食独有的三块**，缺了就没法让妈妈做购买决策。

两条硬约束（沿用 SKILL 铁律）：
1. **屏数 = 本品卖点数 + 铺垫屏**（分阶 / 国标 / 配料 / 演示 / 人群 / 规格 / CTA）。每屏只放大 1 件事。
2. **主文案 ≤ 10 字、副文案 ≤ 12 字**。

### 屏数 / 文案怎么定（判断逻辑，必须走）
1. **收齐本品输入**：产品名 + 卖点清单 + **执行标准号**（这一项辅食必问，决定合规边界）。
2. **搜竞品真实详情页**：找 3-5 家同子类竞品（米粉对米粉、果泥对果泥），记录：几屏、每屏主题、有没有分阶导航、竞品没讲什么。
3. **综合定屏**：竞品都在讲（有机、无添加）→ 打得更实（用国标条文 + 检测）；本品独有（如高蛋白、益生菌、特定颗粒尺寸）→ 单独成屏。
4. **文案基于本品**：不抄竞品、不套空话。"宝宝第一口辅食"是废话，要写"6 个月后铁得靠吃，一次一包"。

### 弹性屏序骨架（可增删，非固定）
| 屏序 | 作用 | 是否必选 |
|------|------|---------|
| 首屏 | 产品 + 月龄 + 一句话价值（"6M+ 第一口" / "12M+ 自己抓着吃"） | 必选 |
| 分阶屏 | 月龄对照：几月吃哪款、质地 / 颗粒 / 每次用量 | **辅食必选（独有）** |
| 国标屏 | 执行标准号 + 国标要求逐条自查（蜂蜜 / 氢化油脂 / 添加糖） | **必选（信任第一锚点）** |
| 配料屏 | 配料表几项 / 无糖无香精无防腐剂 | 必选 |
| 营养屏 | 铁 / 钙 / 维 C / 蛋白含量（有强化才讲） | 卖点屏 ×N |

### 6M+ 高铁米粉 · 实例（9 屏，非固定模板）
卖点：单一谷物、铁强化、不结块、独立小包、无添加糖。本例 5 卖点 → 9 屏；**若某果泥只有"单一水果 + 不加糖"2 卖点，则为 5-6 屏**，不要硬凑。

| 屏 | 主文案(≤10) | 副文案(≤12) | 画面 | 设计理由 |
|----|------------|------------|------|---------|
| 1 首屏 | 六个月第一口 | 从这碗米粉开始 | 冲好的一碗米粉 + 宝宝张口 | 直接锁定月龄，减少无效流量 |
| 2 分阶 | 几月吃哪款 | 6M/8M/12M 对照 | 三档质地 / 颗粒对照图 | 妈妈的第一决策问题就是"买哪段" |
| 3 国标 | 有国标才敢喂 | GB 10769-2025 | 执行标准号特写 | 辅食信任第一锚点，普通零食没有 |
| 4 配料 | 配料表就五样 | 没有糖和香精 | 配料表放大 + 五处打勾 | 把"干净"变成可核对的证据 |
| 5 铁 | 六个月后要补铁 | 一包够一餐 | 铁含量刻度 + 月龄铁需求曲线 | 回应"母传铁耗尽"的育儿焦虑（只讲营养，不讲治贫血） |
| 6 冲调 | 一冲就顺滑 | 不结块不糊嘴 | 冲调过程三步实拍 | 辅食独有的功能演示屏，直接对应最大差评点 |
| 7 安全 | 过敏原都标清 | 颗粒小于米粒 | 过敏原提示 + 尺寸对比 | 回应怕过敏、怕噎两个核心恐惧 |
| 8 规格 | 一次一包 | 外出也方便 | 独立小包 + 出行场景 | 消除"冲调麻烦、不好带"的顾虑 |
| 9 行动 | 按月龄囤一盒 | 分段套装更省 | 分段组合装 + CTA | 辅食按月龄升级，成套买提升客单 |

**关键差异**：辅食是**特殊膳食用食品，饭不是零食**。信任靠"国标 + 配料 + 冲调实证"三类硬证据，不靠氛围图；同时**分阶屏必须前置**，因为妈妈不知道自己该买哪段——这一点没有任何其他品类有。
