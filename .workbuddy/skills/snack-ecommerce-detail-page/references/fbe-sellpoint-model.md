# FBE 卖点转换模型

> "不分析产品有什么，而分析消费者为什么买。"

## 核心转换链

```
产品卖点 (Feature)
    ↓
消费者利益 (Benefit)
    ↓
情绪价值 (Emotion)
    ↓
页面视觉表达
```

## 案例 1：低糖/无添加

| 层级 | 内容 |
|------|------|
| **Feature（产品卖点）** | 低糖 / 无添加 |
| **消费者真正关心** | 孩子喜欢甜味，但妈妈希望控制糖摄入 |
| **Benefit（消费者语言）** | ❌ 不要写"低糖健康"<br>✅ "甜度刚刚好，孩子喜欢，妈妈更安心"<br>✅ "减少甜味负担的儿童零食选择" |
| **Emotion（情绪价值）** | 安心、放心、满足、负责 |
| **视觉表达** | 孩子开心吃零食（注意广告法：不能出现婴儿则展示产品新鲜度或原材料新鲜，产品放在桌子上）<br>构图：平视构图<br>颜色：自然色、偏暖色<br>场景：居家简约风 |

## 案例 2：进口原料

| 层级 | 内容 |
|------|------|
| **Feature** | 进口原料 |
| **消费者真正关心** | 标准、品质、可靠 |
| **Benefit** | ❌ 不要写"欧洲进口品质"<br>✅ "经过严格筛选的优质欧洲原料"<br>✅ "来自欧洲优质产地的自然风味" |
| **Emotion** | 信任、品质保证 |
| **视觉表达** | 用欧洲地图展示产地区域 |

## 案例 3：0添加

| 层级 | 内容 |
|------|------|
| **Feature** | 0添加 |
| **消费者真正关心** | 吃起来更简单、更放心 |
| **Benefit** | ❌ 不要写"0添加"<br>✅ "配料简单，看得懂"<br>✅ "少一些添加，多一些真实" |
| **Emotion** | 简单、纯粹、真实 |
| **视觉表达** | 展示简单配料、天然食材 |

## ⚠️ 食品配料的合规表达（2025 新规，全品类适用）

**GB 7718-2025《预包装食品标签通则》**（2025-03-16 发布、**2027-03-16 实施**，旧版同步废止）明确：**预包装食品不得使用"不添加""零添加""不使用"等用语对配料进行特别强调**；仅当该成分含量为 0 时，方可依法使用"无""不含"等定量声称，**并须有检验材料支撑**。

这意味着**下面这些话术全部作废**——它们是目前食品详情页最常见的写法：

| 停用（2027-03-16 起违规） | 替代写法 |
|--------------------------|---------|
| 不添加白砂糖 / 不加蔗糖 / 不加盐 | **"配料表 X 样"**（正面清单）／ **"糖 X g/100g"**（定量标示） |
| 0 添加 / 无添加 / 零添加 | **"配料表干净，看得懂"**（事实描述）／ 逐项列出配料名称 |
| 不使用防腐剂 / 无香精色素 | **"配料表里没有 XX 这几个字"**（引导消费者自查） |
| 不含蔗糖 | 仅在实测为 0 且备有检验材料时才可用"不含蔗糖" |

两条配套变化同样影响页面：
- **八大致敏物质强制标示**（麸质谷物、甲壳纲动物、鱼类、蛋类、花生、大豆、乳及乳制品、坚果及其果仁类制品）——详情页应复现致敏提示；**同时含乳和坚果等两类以上的，须双类标注**。
- **营养成分表由"1+4"扩至"1+6"**，新增 **糖** 与 **饱和脂肪（酸）** 为强制项——讲"控糖/低甜"必须**亮糖含量数字**，空喊不足以支撑。

> **给策划的启示：**"不添加"是主观表态，"配料表 6 样 + 糖 1.2g"是可核对的事实。新规逼着行业从"喊没有"转向"给数据"，**这对愿意把配料表摊开的产品是机会，对只会喊口号的品牌是灾难**——策划时应主动把品类里普遍在用的"不加"话术改写掉，抢在前面。

## FBE 转换检查清单

对每个卖点，必须完成以下转换才可通过：
- [ ] Feature：产品到底有什么？（具体事实）
- [ ] Consumer Truth：消费者真正在乎什么？（深层需求）
- [ ] Benefit：翻译成人话怎么说？（一句话能懂）
- [ ] Emotion：让人产生什么感觉？（安心/满足/信任/放心）
- [ ] Visual：画面怎么表现？（构图/颜色/场景）
